### WebFetch Notes

- Chinese tech platforms (腾讯云, 阿里云, Apifox) generally accessible via WebFetch

## Research Patterns
- Always search both Chinese and English terms (5+ queries)
- Chinese AI ecosystem often has unique adaptations (e.g., 飞书/钉钉 integrations, 国产模型 like DeepSeek/GLM)
- For installation guides: check official docs, GitHub README, and community tutorials
- Security considerations are increasingly important for AI agent tools
