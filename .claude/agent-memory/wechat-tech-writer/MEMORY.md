# WeChat Tech Writer - Agent Memory

## Writing Patterns
- User provides research report + outline as input files, expects article output directly (not saved to file)
- Article topics so far: OpenClaw installation guide (AI Agent platform)
- Target audience: tech-curious readers with basic command-line skills, emphasis on Chinese mainland users

## Style Preferences
- Conversational connectors work well: "说白了", "换句话说", "想象一下"
- Avoid "本文", "笔者", "综上所述" - use "我的建议是" for personal recommendations
- Research reports may contain tables that need to be converted to bullet lists or prose in the article
- Security warnings should be woven throughout, not just at the end
- Code blocks are essential for installation guides - include complete commands with comments

## Content Domain
- AI tools, open-source projects, developer productivity
- Strong focus on China-specific solutions (domestic LLMs, Chinese IM platforms, localized versions)

## Outline Adherence
- Outlines include word count targets per section, transition sentences, and specific material requests (code, quotes, cases)
- Follow the outline structure closely but adapt prose naturally
