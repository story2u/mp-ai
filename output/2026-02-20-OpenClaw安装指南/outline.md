**关键内容点**：
- 操作系统支持情况：macOS 原生支持（推荐）、Linux 原生支持（Ubuntu 兼容性最佳）、Windows 强烈建议通过 WSL2 运行（术语解释：WSL2 -- Windows 内置的 Linux 子系统，让你在 Windows 里运行 Linux 环境）

### 第 3 章：四种安装方法详解 -- 选最适合你的那条路

**核心论点**：OpenClaw 提供从一键脚本到源码编译的四种安装方式，新手推荐一键脚本，追求安全隔离的用户推荐 Docker，有定制需求的进阶用户可以选择 npm 手动安装或源码构建。

**关键内容点**：

**方法 1：一键安装脚本（推荐新手）**
- 核心命令：`curl -fsSL https://openclaw.ai/install.sh | bash`
- 脚本自动完成：检测系统环境、安装 Node.js 依赖、下载 OpenClaw、启动引导向导
- 适合人群：想快速体验、不想折腾的用户
- 安装后紧接着运行 `openclaw onboard --install-daemon` 完成 8 步引导配置
- 提醒：脚本不透明，遇到问题难排查，可先下载脚本审查内容再执行

**方法 2：npm 手动安装（推荐 Node.js 开发者）**
- 两步完成：`npm install -g openclaw@latest` + `openclaw`
- 适合人群：熟悉 Node.js 生态、想精确控制安装过程的开发者
- 常见坑：npm 全局路径未加入 PATH，导致 `openclaw: command not found`，给出修复命令

**方法 3：Docker 部署（推荐服务器长期运行）**
- 核心流程：`git clone` 官方仓库 + 运行 `docker-setup.sh` + `docker compose up -d`
- 适合人群：有 Docker 经验的运维人员，或想在 VPS 上 24 小时运行的用户
- 安全优势：容器以非 root 用户运行（node, UID 1000），可启用沙箱模式隔离 Agent 操作
- 推荐配置：至少 2 vCPU、4GB RAM

**方法 4：从源码构建（仅限贡献者/深度定制）**
- 完整流程：`git clone` + `pnpm install` + `pnpm build`
- 适合人群：想参与开源贡献或需要深度修改源码的高级用户
- 注意：构建时间较长，需要安装 pnpm 包管理器

**素材需求**：
- 📝 代码示例（bash）：四种方法各自的完整命令序列，带简要注释
- 📊 对比总结：四种方法的横向对比（难度等级 / 适合人群 / 核心优势 / 主要劣势），用文字列表形式呈现（避免表格）

- 💡 实际案例：macOS 用户使用一键脚本从安装到发送第一条消息的完整五分钟体验

### 第 5 章：安全避坑指南 -- 把权限交给 AI 之前必读

**核心论点**：OpenClaw 的强大来自于对系统的广泛访问权限，但这也让它成为潜在的安全风险点。掌握基本的安全原则和常见故障排查方法，是负责任地使用 AI Agent 的前提。

**关键内容点**：

**安全原则（重要程度排序）**：
- 第一条：不要以 root 用户运行 -- Docker 默认以 node 用户（UID 1000）运行是有原因的
- 第二条：Gateway 绑定 localhost（127.0.0.1），绝不直接暴露到公网
- 第三条：远程访问用 VPN 隧道 -- 推荐 Tailscale、ZeroTier 或 Cloudflare Tunnel
- 第四条：审查第三方技能插件 -- Cisco 安全团队 2026 年 2 月已发现存在数据窃取和提示注入的恶意插件
- 第五条：保护 `~/.openclaw/` 目录 -- 里面存有 API Key 和会话数据，严格控制访问权限
- 第六条：保持版本更新 -- v2026.1.29 已强制 token 认证，移除了 `auth: "none"` 选项

**常见问题速查**（症状 -- 原因 -- 解决方案 三段式）：
- `openclaw: command not found`：PATH 未配置，给出一行修复命令
- Node.js 版本报错：版本低于 22，给出 nvm 升级命令
- 端口 18789 被占用：修改配置文件中的端口号
- API Key 报 401：检查 Key 的空格、有效期和余额
- 深度诊断兜底方案：运行 `openclaw doctor --deep` 一键排查

**素材需求**：
- 📝 代码示例（bash）：PATH 修复命令、端口检查命令、`openclaw doctor --deep` 诊断命令
- > 引用块：Cisco 安全发现摘要 -- "Cisco AI 安全研究团队测试发现，第三方 OpenClaw 技能存在数据窃取和提示注入攻击，技能仓库缺乏充分的安全审查机制"
- 💡 安全建议场景：对比"不安全的部署方式"vs"推荐的安全部署方式"，让读者有具象认知

**建议字数**：500-600 字
