## 三、正文章节

### 第 1 章：OpenClaw 是什么 -- 不只是聊天机器人

**核心论点**：OpenClaw 是一个开源的自主 AI 智能体平台，它不发明新模型，而是把现有大模型的能力"接入"到你的日常工具中，让 AI 真正帮你干活。

**关键内容点**：
- OpenClaw 的定位：不是 AI 模型，而是一个"连接器"和"执行器"，把 Claude、GPT、DeepSeek 等模型的智能接入 WhatsApp、Telegram、飞书、钉钉等聊天工具
- 它能做什么：处理邮件、管理日历、编写代码、操作文件、控制智能家居 -- 用自然语言下指令即可
- 核心设计理念：本地优先、隐私可控，所有数据由用户自己掌控，不经过第三方服务器
- 项目热度：GitHub 超过 20 万 Star，35,000+ Fork，社区技能插件 1700+，MIT 开源许可证
- 最新动态（术语解释："自主 AI 智能体"指能独立规划并执行多步骤任务的 AI 程序，区别于只能一问一答的聊天机器人）

**素材需求**：
- 架构示意图：展示 Gateway（网关）- Agent（智能体）- Skills（技能）三层架构关系，以及与聊天平台、LLM 的连接方式
- 场景案例：用一个简短例子说明用户通过 Telegram 发消息让 OpenClaw 帮忙总结邮件的完整流程
- 引用块：Peter Steinberger 关于项目理念的核心表述

**建议字数**：400-500 字

**过渡句**：了解了 OpenClaw 是什么之后，接下来的问题是 -- 你的电脑能不能跑得动它？

### 第 2 章：安装前的准备 -- 先检查你的装备

**核心论点**：安装 OpenClaw 之前，确认系统环境和必要依赖到位，能避免 80% 的安装失败问题。

**关键内容点**：
- 操作系统要求：macOS 原生支持（推荐）、Linux 原生支持（Ubuntu 兼容性最佳）、Windows 强烈推荐通过 WSL2 运行
- 核心依赖：Node.js >= 22 是硬性要求，低版本会直接报错。简要说明如何检查和升级 Node.js 版本
- 需要准备的东西：一个 LLM 的 API Key（推荐 Anthropic Claude 或 OpenAI，国内用户可选 DeepSeek）、一个常用的聊天平台账号（WhatsApp / Telegram / 飞书 / 钉钉）
- 建议：准备一个专用的测试环境或虚拟机，不要在个人主力设备上直接安装（安全考量）

**素材需求**：
- 代码示例（bash）：检查 Node.js 版本的命令 `node -v`，以及使用 nvm 安装 Node.js 22 的命令
- 表格：三大操作系统的支持情况对比表（系统 / 支持程度 / 注意事项）

**建议字数**：300-400 字

**过渡句**：环境准备就绪，现在进入正题 -- 四种安装方式，总有一种适合你。

### 第 3 章：四种安装方法详解 -- 选最适合你的那条路

**核心论点**：OpenClaw 提供从一键脚本到源码编译的四种安装方式，新手推荐一键脚本，有定制需求的用户可以选择 Docker 或源码构建。

**关键内容点**：

**方法 1：一键安装脚本（推荐新手）**
- 一行命令搞定，脚本自动检测环境、下载依赖、完成安装
- 适合人群：想快速体验、不想折腾的用户

**方法 2：手动 npm 安装**
- 两步完成：全局安装 + 启动引导向导
- 适合人群：熟悉 Node.js 生态的开发者，想精确控制安装过程

**方法 3：Docker 部署**
- 容器化运行，环境隔离，便于管理
- 适合人群：有 Docker 经验的运维人员，或想在服务器上长期运行的用户

**方法 4：从源码构建**
- 完整克隆仓库，手动编译，可定制修改
- 适合人群：想参与开发或深度定制的高级用户

**素材需求**：
- 代码示例（bash）：四种方法各自的完整命令，带逐行注释
- 对比表格：四种方法的"难度 / 适合人群 / 优势 / 劣势"横向对比
- 引用块：强调推荐新手使用方法 1 的建议

**建议字数**：600-800 字（本章为全文重点章节）

**过渡句**：安装完成后，OpenClaw 会启动一个引导向导，帮你完成最关键的初始化配置。

### 第 4 章：初始化配置 -- 让 AI 助手认识你

**核心论点**：安装只是开始，通过 Onboarding Wizard（引导向导）完成 API Key 配置、通信渠道选择和技能安装，OpenClaw 才能真正为你工作。

**关键内容点**：
- 引导向导的 8 个步骤概览：安全确认 - 安装模式 - LLM 提供商 - API Key - 默认模型 - 通信渠道 - 技能安装 - 守护进程注册
- 重点步骤详解：
  - 配置 LLM 提供商：海外用户推荐 Anthropic（模型选 Sonnet 4.5），国内用户可选 DeepSeek 降低成本和延迟
  - 选择通信渠道：国内用户重点关注飞书和钉钉的接入方式
  - 技能安装建议：初次使用建议只安装核心技能（如邮件、日历、网页搜索），后续按需添加
- 守护进程的作用（术语解释："守护进程"是一个在后台持续运行的服务，确保 OpenClaw 的 Gateway 始终在线，即使关闭终端窗口也不会中断）

**素材需求**：
- 流程图：Onboarding Wizard 的 8 步流程图，标注每一步的关键选择
- 国内用户特别提示：飞书/钉钉接入的配置要点
- 代码示例：启动引导向导的命令，以及手动修改配置文件的路径说明

**建议字数**：500-600 字

**过渡句**：配置完成后，你可能会遇到一些常见问题。别慌，大部分都有现成的解决方案。

### 第 5 章：避坑指南与安全须知

**核心论点**：提前了解常见报错和安全注意事项，能让你的 OpenClaw 运行得更稳、更安全。

**关键内容点**：

**常见问题排查**（每个问题用"症状 - 原因 - 解决方案"三段式呈现）：
- `openclaw: command not found`：npm 全局路径未加入 PATH，给出具体的修复命令
- Node.js 版本不兼容：提示需要 >= 22，给出升级方法
- Gateway 启动失败或端口占用：排查端口冲突的方法
- API Key 无效 / 401 错误：检查 Key 的有效性和配额
- 配置修改不生效：需要重启 Gateway（很多人会忽略这一步）

**安全须知**（重要程度排序）：
- 不要以 root 用户运行 -- 这是最重要的安全原则
- 将服务绑定到 localhost，不要暴露到公网
- 审查社区技能插件 -- Cisco 安全团队已发现第三方插件存在数据窃取和提示注入风险
- 保护 ~/.openclaw 目录的权限
- 2026 年 1 月安全更新已强制要求 token 认证，请确保使用最新版本

**素材需求**：
- 代码示例（bash）：修复 PATH 问题、检查端口占用、重启 Gateway 的具体命令
- 引用块：Cisco 安全报告的关键发现摘要
- 表格：常见问题速查表（症状 / 原因 / 一句话解决方案）

## 四、总结章节

**核心观点回顾**：
1. OpenClaw 是一个开源 AI 智能体平台，通过接入大语言模型让 AI 在日常聊天工具中帮你执行实际任务
2. 安装前确认 Node.js >= 22 和操作系统兼容性，是避免问题的关键
3. 四种安装方法中，一键脚本最适合新手快速上手，Docker 适合长期部署
4. 初始化配置的核心是选对 LLM 提供商和通信渠道，国内用户可优先考虑 DeepSeek + 飞书/钉钉的组合
5. 安全意识不可少：不用 root 运行、绑定 localhost、审查第三方插件
